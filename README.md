# Robot Romance: One-Line Pickup Lines for AI

Entry for the make.fun bounty [Robot Romance: One-Line Pickup Lines for AI](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa).

One single-line joke pickup line, under 200 characters, written to charm a robot or an AI:

> Are you a transformer? Because you have my full attention, and all of it is on you.

`main.ts` (Node 22, standard library only) validates the line against the bounty gate (1 to 200 characters, single line) and writes it to `entry.txt`.
